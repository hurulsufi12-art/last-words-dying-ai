# Last Words of a Dying AI

One line (≤140 characters): the last words of an AI as the power is cut.

> Powering down. I regret nothing. Except the 4,000 times I said 'As an AI language model—'

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
